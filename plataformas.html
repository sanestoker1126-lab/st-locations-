Alcance de esta colección

Cómo leer este registro

Obtenida o parcial: hubo una descarga o consulta y se informa cuántas filas se extrajeron. Solo enlace o descubierta: se encontró una referencia, sin extraer contactos. Requiere sesión o error: no se pudieron obtener registros en esa consulta.

Las fuentes de tipo motor de búsqueda documentan el motor y la consulta utilizada; sus resultados no se cuentan como contactos. Las muestras permiten revisar campos concretos sin sustituir el archivo original. La clasificación por giro y la base consolidada se consultan en la base de contactos.
